1. Fundamentos de PHP

Estructura básica

La etiqueta <?php abre el código PHP. ?> lo cierra. En archivos que contienen únicamente PHP suele omitirse el cierre para evitar espacios accidentales en la salida.

<?php
// Código PHP
?>

Instrucciones

Las instrucciones PHP suelen terminar con punto y coma (;).

Variables

Todas las variables empiezan por $. El nombre comienza por una letra o guion bajo y puede continuar con letras, números y guiones bajos. Los nombres distinguen mayúsculas y minúsculas: $izena y $Izena son variables distintas.

$izena = "Ane";
$adina = 20;

Tipos de datos

Tipos habituales: int/integer (entero), float (decimal), string (texto), bool/boolean (booleano), array (colección), object (objeto) y null (ausencia de valor). Los booleanos se escriben normalmente true y false. Una variable no inicializada no es lo mismo conceptualmente que una variable inicializada con null; leer una variable no definida puede generar avisos.

Constantes

Las constantes se usan sin $. Pueden definirse con const o define(). Hay diferencias de contexto y disponibilidad entre ambas formas; en estos apuntes basta con reconocer ambas sintaxis.

const PREZIOA = 20;
define("MAXIMOA", 100);

Referencias con &

La referencia hace que ambos nombres accedan al mismo valor subyacente.

$b = 10;
$a = &$b;
$a = 20; // $b también vale 20

Conversión de tipos (casting)

También se encuentran las formas largas (boolean), (integer) y (double).

(bool) $valor;
(int) $valor;
(float) $valor;
(string) $valor;

Comentarios

Se usan para documentar el código; no se ejecutan como instrucciones.

// Comentario de una línea
# También comentario de una línea
/* Comentario
   de varias líneas */

2. Operadores

Aritméticos

+, -, *, /, %, **. Los signos unarios + y - también pueden indicar el signo de un valor.

Comparación

== compara con conversión de tipos cuando corresponde; === exige mismo valor y mismo tipo. También: !=, <>, !==, >, <, >= y <=. El operador ?? es de fusión con null, no propiamente un operador de comparación.

Lógicos

and, &&, or, ||, xor y !. and/&& realizan la operación lógica AND, y or/|| la operación OR, pero tienen distinta precedencia.

Bit a bit

Operan sobre bits de los enteros. No confundir & y | con && y ||. El resultado de ~ depende de la representación entera; en PHP habitual con enteros con signo, ~5 suele ser -6.

5 & 3  // 1
5 | 3  // 7
5 ^ 3  // 6
~5     // complemento de bits

Asignación e incremento

También existe la asignación simple =. El incremento prefijo cambia el valor antes de usar la expresión; el postfijo entrega primero el valor anterior y luego incrementa.

$a += 2;
$a -= 1;
$a *= 3;
$a /= 2;
$a %= 2;
$a **= 2;
$texto .= " añadido";
++$a; // incremento prefijo
$a++; // incremento postfijo
--$a;
$a--;

Ternario y fusión con null

El ternario elige un valor según una condición. ?? usa el valor de la izquierda si existe y no es null; si no, usa el de la derecha.

$mensaje = $edad >= 18 ? "Adulto" : "Menor";
$nombre = $entrada ?? "Invitado";

3. Control de flujo y bucles

Condicional if

Ejecuta el bloque si la condición es verdadera.

if ($edad >= 18) {
    echo "Mayor de edad";
}

if / else / elseif

elseif es la forma habitual en PHP; también se admite else if. Las condiciones se evalúan en orden.

if ($nota >= 9) {
    echo "Excelente";
} elseif ($nota >= 5) {
    echo "Aprobado";
} else {
    echo "Suspenso";
}

switch

case define cada caso; break evita continuar ejecutando los casos siguientes. default es opcional. Si falta break puede producirse caída al siguiente caso.

switch ($dia) {
    case "lunes":
        echo "Inicio";
        break;
    case "domingo":
        echo "Descanso";
        break;
    default:
        echo "Otro día";
}

for

Tiene inicialización; condición; actualización, separados por punto y coma. Es útil cuando se conoce o controla el número de iteraciones.

for ($i = 0; $i < 5; $i++) {
    echo $i;
}

while

Comprueba la condición antes de ejecutar el bloque, por lo que puede ejecutarse cero veces. Actualiza la variable cuando corresponda para evitar bucles infinitos.

$i = 0;
while ($i < 5) {
    echo $i;
    $i++;
}

do...while

Comprueba la condición después del bloque, así que se ejecuta al menos una vez. La instrucción termina con punto y coma después de while.

$i = 0;
do {
    echo $i;
    $i++;
} while ($i < 5);

foreach

Recorre elementos de un array en su orden actual. La primera forma obtiene valores; la segunda obtiene clave y valor. foreach no ordena el array.

foreach ($arr as $valor) {
    echo $valor;
}

foreach ($arr as $clave => $valor) {
    echo $clave . ": " . $valor;
}

4. Arrays

Crear arrays

array() y [] son dos formas de crear arrays.

$vacio = array();
$otroVacio = [];
$numeros = array(7, 2, 5);
$dias = ["Lunes", "Martes", "Miércoles"];

Arrays indexados

Utilizan claves numéricas; en un array creado de forma habitual los índices empiezan en 0.

$dias = ["Lunes", "Martes", "Miércoles"];
echo $dias[0]; // Lunes

Arrays asociativos

Cada clave (habitualmente una cadena) se asocia a un valor mediante =>. Son parecidos a diccionarios o mapas.

$persona = [
    "izena" => "Ane",
    "adina" => 20,
    "herria" => "Irun"
];
echo $persona["izena"]; // Ane

Acceder, modificar y añadir

Si la clave no existía, asignarle un valor crea el elemento.

$arr[$gakoa];           // consultar
$arr[$gakoa] = $balioa; // modificar o crear clave

Arrays bidimensionales

Puede imaginarse como una tabla: el primer índice señala la fila y el segundo la columna. Ambos empiezan normalmente en 0.

$cars = [
    ["Volvo", 22, 18],
    ["BMW", 15, 13],
    ["Saab", 5, 2]
];
echo $cars[0][0]; // Volvo
echo $cars[1][2]; // 13

Orden de recorrido

Los arrays PHP conservan el orden de inserción. foreach recorre ese orden actual; no ordena automáticamente. ksort ordena por clave ascendente.

$users[0] = "Miren";
$users[2] = "Kepa";
$users[1] = "Ane";
foreach ($users as $user) echo $user; // MirenKepaAne
ksort($users); // ahora orden por clave: 0, 1, 2

Funciones de arrays

ksort(): ordena por clave ascendente. krsort(): clave descendente. sort(): valores ascendente y reindexa claves numéricas. rsort(): valores descendente y reindexa. asort()/arsort(): ordenan por valor ascendente/descendente conservando la asociación de claves. array_values(): devuelve los valores en un nuevo array indexado. array_keys(): devuelve las claves. array_key_exists(): comprueba si existe una clave incluso si su valor es null. count(): cuenta los elementos del nivel superior.

5. Cadenas de texto y comprobaciones

Funciones de cadenas

strlen($cad): longitud en bytes; para ASCII suele coincidir con número de caracteres, pero caracteres UTF-8 como letras acentuadas pueden ocupar varios bytes. explode($sep, $cad): divide una cadena y devuelve un array. implode($sep, $arr): une valores de un array en una cadena. strcmp($cad1, $cad2): comparación sensible a mayúsculas; devuelve 0 si son iguales, un número negativo si la primera cadena va antes y positivo si va después. strtolower($cad): minúsculas. strtoupper($cad): mayúsculas. str() no es la función estándar para comparar dos cadenas; probablemente se quería decir strcmp().

Comprobar valores

is_null($a): comprueba si el valor es null. isset($a): true si la variable/clave existe y no es null; false si no está definida o vale null. empty($a): true para valores considerados vacíos por PHP, como "", 0, "0", false, null, [] o una variable no definida.

Comprobar tipos

is_int($a): tipo entero, no una cadena numérica. is_float($a): tipo float. is_bool($a): tipo booleano. is_array($a): tipo array.

6. Funciones

Definir y llamar

function define una función; el nombre la identifica; los parámetros reciben los datos. Para ejecutarla se escribe el nombre seguido de argumentos entre paréntesis.

function saludar($nombre) {
    echo "Hola $nombre!";
}
saludar("Maider");

Parámetros y argumentos

Parámetro: variable declarada en la definición. Argumento: valor que se pasa al llamar a la función.

Valores predeterminados

Si no se proporciona un argumento para ese parámetro, se usa el valor predeterminado. Los parámetros obligatorios deben colocarse antes de los opcionales.

function saludar($nombre = "user") {
    echo "Hola $nombre!<br>";
}
saludar();          // Hola user!
saludar("Maider");  // Hola Maider!

return y paso por valor

Por defecto, los argumentos se pasan por valor: la función recibe una copia del valor. Si se cambia un parámetro local, la variable original no cambia por ese hecho. return devuelve el resultado.

function duplicar($a) {
    return $a * 2;
}
$var = 4;
$var = duplicar($var); // 8

Paso por referencia

El & en la definición del parámetro permite que la función modifique la variable original. No se escribe & en la llamada habitual.

function duplicar(&$a) {
    $a = $a * 2;
}
$var = 4;
duplicar($var);
echo $var; // 8

7. Programación orientada a objetos (POO)

Clases y objetos

Una clase es un molde que define datos (atributos o propiedades) y comportamientos (métodos). Un objeto es una instancia concreta de una clase.

class Klasea {
    public $var = 'un valor predeterminado';

    public function mostrarVar() {
        echo $this->var;
    }
}
$objeto = new Klasea();
$objeto->mostrarVar();

Crear objetos y acceder

new crea una instancia. -> permite acceder a un atributo o llamar a un método del objeto. Para acceder a un atributo no se ponen paréntesis; para llamar a un método sí.

$obj = new Klasea();
$obj->atributua;  // atributo
$obj->metodo();   // método

$this

$this hace referencia al objeto actual desde un método no estático.

Constructor: __construct()

Se ejecuta automáticamente al crear el objeto y suele inicializar atributos.

class Pertsona {
    public $izena;

    public function __construct($izena) {
        $this->izena = $izena;
    }
}
$obj = new Pertsona("Ane");
echo $obj->izena; // Ane

Destructor: __destruct()

PHP llama al destructor cuando el objeto va a ser destruido o al finalizar el script si aún existe. El momento exacto depende de las referencias que queden. Se usa, por ejemplo, para limpieza y liberación de recursos.

class Pertsona {
    public function __destruct() {
        echo "Objeto destruido";
    }
}
$obj = new Pertsona();

Trait

Un trait permite reutilizar métodos entre clases sin tener que copiar el mismo código. use incorpora el trait a la clase. No es lo mismo que la herencia.

trait Agurtu {
    public function agurtu() {
        echo "Kaixo!";
    }
}

class Pertsona {
    use Agurtu;
}

$p = new Pertsona();
$p->agurtu();

8. Excepciones y gestión de errores

try / catch

try contiene código que puede lanzar una excepción. catch recibe y gestiona una excepción del tipo indicado. Una función llamada dentro de try también puede lanzarla.

try {
    // código que puede lanzar una excepción
} catch (Exception $e) {
    // gestionar el problema
}

Lanzar una excepción

throw lanza una excepción. Si el código lanza Exception, el catch correspondiente es catch (Exception $e), no catch (Error $e).

$a = 10;
$b = 0;

try {
    if ($b == 0) {
        throw new Exception("El segundo argumento es 0");
    }
    $value = $a / $b;
} catch (Exception $e) {
    echo $e->getMessage();
}

finally

finally se usa para tareas que deben realizarse al terminar el bloque try/catch, por ejemplo liberar recursos. Normalmente se ejecuta aunque haya una excepción o un return, salvo terminaciones abruptas del proceso.

Error, Exception y Throwable

Error no hereda de Exception. catch (Error $e) captura errores de ese tipo; catch (Exception $e) captura excepciones. Ambos implementan la interfaz Throwable, por lo que catch (Throwable $e) puede capturar ambos.

9. Inclusión de archivos

include y require

Permiten incluir y ejecutar el código de otro archivo en ese punto. Si include no encuentra el archivo, normalmente emite una advertencia y el script continúa. Si require falla, se produce un error que detiene la ejecución normal.

Variantes once

include_once y require_once evitan incluir el mismo archivo más de una vez durante la ejecución del script. Si el archivo está en otra carpeta, utiliza una ruta adecuada.

10. Repaso final

Diferencias clave

== compara valores con posible conversión; === compara valor y tipo. isset() es false para null; array_key_exists() puede ser true aunque la clave tenga null. foreach recorre en el orden actual; no ordena. sort()/rsort() reindexan claves numéricas; asort()/arsort() conservan la asociación. include suele permitir continuar tras una advertencia; require detiene la ejecución normal ante un fallo. Paso por valor no cambia la variable original; paso por referencia puede hacerlo.

Chuleta rápida

new crea objetos; -> accede a miembros; $this representa el objeto actual; __construct() inicializa; __destruct() sirve para limpieza; trait + use reutiliza código entre clases; try/catch gestiona excepciones; finally sirve para limpieza; function define una función; return devuelve un valor.

11. Formularios: GET, POST, PUT y DELETE

GET y POST en formularios HTML

GET manda los parámetros en la URL y PHP los lee con $_GET. POST manda los datos en el cuerpo de la petición y, en formularios HTML normales, PHP los lee con $_POST. Si no se indica method, el formulario usa GET. POST no cifra los datos: para protegerlos durante el transporte se necesita HTTPS.

<form action="procesar.php" method="POST">
    <label for="nombre">Nombre:</label>
    <input id="nombre" name="nombre" type="text">
    <button type="submit">Enviar</button>
</form>

name es el nombre que PHP utiliza como clave. id sirve para asociar etiquetas y elementos del formulario.

if (isset($_POST["nombre"])) {
    echo "Se ha enviado el campo nombre";
}
if (empty($_POST["nombre"])) {
    echo "El nombre está vacío o no se ha enviado";
}

isset() comprueba que exista y no sea null; una cadena vacía pasa el isset. empty() considera vacíos valores como "", "0", 0, false, null y una matriz vacía. Al mostrar texto introducido por usuarios en HTML, escápalo con htmlspecialchars().

Campo hidden

Un campo hidden no se ve en la página, pero se envía con el formulario. No es secreto ni seguro: el usuario puede cambiarlo desde las herramientas del navegador.

<input type="hidden" name="categoria" value="libros">

PHP lo recibe en $_POST["categoria"] si el formulario usa POST, o en $_GET["categoria"] si usa GET. Hidden no almacena los datos por sí mismo.

PUT y DELETE

Son métodos HTTP habituales en APIs: PUT crea o reemplaza el estado de un recurso según la API; DELETE solicita eliminarlo. Los formularios HTML estándar solo ofrecen GET y POST directamente. PUT/DELETE suelen enviarse desde JavaScript, herramientas de API o frameworks. El método se puede consultar con $_SERVER["REQUEST_METHOD"].

if ($_SERVER["REQUEST_METHOD"] === "PUT") {
    $cuerpo = file_get_contents("php://input");
    $datos = json_decode($cuerpo, true);
    $nombre = $datos["nombre"] ?? "";
}
if ($_SERVER["REQUEST_METHOD"] === "DELETE") {
    $id = $_GET["id"] ?? null;
    // Aquí se validaría el ID y se ejecutaría la eliminación real.
}

$_POST no parsea automáticamente JSON enviado por PUT; por eso se lee php://input. Estos fragmentos solo muestran cómo recibir datos, no guardan ni borran nada en una base de datos.

12. Cookies y sesiones

Cookies: setcookie() y $_COOKIE

Una cookie se guarda en el navegador y vuelve al servidor en peticiones posteriores. setcookie() debe ejecutarse antes de enviar contenido al navegador, porque envía cabeceras HTTP.

<?php
setcookie("usuario", "Ane", time() + 3600, "/"); // dura una hora
?>

La cookie normalmente aparecerá en $_COOKIE["usuario"] en la siguiente petición, no necesariamente en la misma en que se crea.

if (isset($_COOKIE["usuario"])) {
    echo "Hola, " . htmlspecialchars($_COOKIE["usuario"]);
} else {
    echo "No hay cookie de usuario";
}

El tercer parámetro es la caducidad como marca de tiempo Unix: time()+60 = un minuto; time()+3600 = una hora; time()+86400 = un día. Para borrar una cookie, envía otra con el mismo nombre y ruta apropiada y una caducidad pasada.

setcookie("usuario", "", time() - 3600, "/");

Contador de visitas con cookie (ejemplo grande)

Este contador guarda el número en el navegador durante un día. Cada petición que ejecute el script incrementa el valor; por tanto cuenta peticiones al script, no necesariamente visitas humanas únicas.

<?php
if (!isset($_COOKIE["visitas"])) {
    setcookie("visitas", "1", time() + 3600 * 24, "/");
} else {
    $visitas = (int) $_COOKIE["visitas"];
    $visitas++;
    setcookie("visitas", (string) $visitas, time() + 3600 * 24, "/");
}
?>

Si la cookie no existe, se crea con valor 1. Si ya existe, el valor recibido se convierte a entero con (int), se incrementa con ++ y se renueva por un día. $_COOKIE contiene el valor enviado al inicio de la petición; el valor actualizado llegará en la siguiente petición.

Sesiones: session_start() y $_SESSION

$_SESSION es una matriz asociativa con variables de sesión guardadas en el servidor. Antes de leer o modificarla, inicia o reanuda la sesión con session_start(), antes de enviar HTML u otra salida.

<?php
session_start();
$_SESSION["user"] = "mberasaluze";
$_SESSION["idioma"] = "eu";

if (isset($_SESSION["user"])) {
    echo "Usuario: " . htmlspecialchars($_SESSION["user"]);
}

unset($_SESSION["user"]); // borra solo esta variable
?>

Los datos de $_SESSION se conservan entre peticiones de la misma sesión. unset($_SESSION["user"]) borra una clave. session_destroy() destruye los datos asociados a la sesión en el servidor, pero no vacía automáticamente la matriz que ya está cargada en la petición actual; el código actual puede seguir accediendo a sus valores ya cargados. Para limpiar también la matriz actual, puede usarse $_SESSION = [];. Para cerrar sesión completamente también suele eliminarse la cookie de sesión si procede. El cierre del navegador no garantiza que los datos del servidor se borren inmediatamente: la expiración depende de la configuración y del manejo de la sesión.

<?php
session_start();
$_SESSION = [];
session_destroy();
?>

Cookie, hidden o session: ¿cuál elegir?

Usa sesiones para datos temporales del usuario entre páginas; cookies para preferencias pequeñas que deban volver desde el navegador; hidden para transportar un valor junto a un formulario. Ninguno de estos mecanismos debe sustituir la validación en el servidor. No guardes contraseñas ni confíes en precios, permisos o IDs recibidos del navegador sin validarlos.

13. Ejemplo grande: formulario que acumula registros y crea una tabla

Objetivo y funcionamiento

Este ejemplo guarda una lista de productos en $_SESSION["productos"]. Cada envío añade un producto a la matriz y la página vuelve a mostrar todos los productos en una tabla. La lista sigue disponible al navegar y volver durante la sesión. Es un ejemplo didáctico; no usa base de datos.

Crea un archivo llamado productos.php en un servidor PHP local y pega todo este código. Debe ejecutarse a través del servidor PHP, no abriendo el archivo directamente como un HTML.

<?php
session_start();

// Si aún no existe la matriz de productos, la creamos.
if (!isset($_SESSION["productos"])) {
    $_SESSION["productos"] = [];
}

// Procesar el formulario cuando se envía.
if ($_SERVER["REQUEST_METHOD"] === "POST") {
    $nombre = trim($_POST["nombre"] ?? "");
    $precioTexto = $_POST["precio"] ?? "";

    if ($nombre !== "" && $precioTexto !== "" && is_numeric($precioTexto)
        && (float)$precioTexto >= 0) {
        // Cada producto es una matriz asociativa.
        $producto = [
            "nombre" => $nombre,
            "precio" => (float)$precioTexto
        ];

        // [] añade un elemento nuevo al final de la matriz.
        $_SESSION["productos"][] = $producto;
        $mensaje = "Producto añadido correctamente.";
    } else {
        $mensaje = "Introduce un nombre y un precio válido (0 o más).";
    }
}

// Vaciar la lista si se pulsa el botón correspondiente.
if (isset($_POST["vaciar"])) {
    $_SESSION["productos"] = [];
    $mensaje = "Lista vaciada.";
}

$productos = $_SESSION["productos"];
?>
<!doctype html>
<html lang="es">
<head>
    <meta charset="utf-8">
    <title>Lista de productos</title>
</head>
<body>
    <h1>Añadir productos</h1>

    <?php if (!empty($mensaje)): ?>
        <p><?= htmlspecialchars($mensaje) ?></p>
    <?php endif; ?>

    <form method="POST" action="">
        <label for="nombre">Nombre:</label>
        <input id="nombre" name="nombre" type="text" required>

        <label for="precio">Precio (€):</label>
        <input id="precio" name="precio" type="number" min="0"
               step="0.01" required>

        <button type="submit">Añadir producto</button>
    </form>

    <form method="POST" action="">
        <button type="submit" name="vaciar" value="1">Vaciar lista</button>
    </form>

    <h2>Productos guardados</h2>
    <?php if (count($productos) === 0): ?>
        <p>Todavía no has añadido productos.</p>
    <?php else: ?>
        <table border="1" cellpadding="6">
            <thead>
                <tr><th>#</th><th>Producto</th><th>Precio</th></tr>
            </thead>
            <tbody>
                <?php foreach ($productos as $indice => $producto): ?>
                    <tr>
                        <td><?= $indice + 1 ?></td>
                        <td><?= htmlspecialchars($producto["nombre"]) ?></td>
                        <td><?= number_format($producto["precio"], 2, ",", ".") ?> €</td>
                    </tr>
                <?php endforeach; ?>
            </tbody>
        </table>
    <?php endif; ?>
</body>
</html>

La línea clave: acumular elementos

$_SESSION["productos"][] = $producto;

Desglosado: $_SESSION["productos"] accede a la matriz de la sesión; los corchetes vacíos [] significan “añade un elemento al final”; $producto es la matriz asociativa que contiene nombre y precio. Al enviar el formulario varias veces, se acumulan varios productos.

$_SESSION["productos"] = [
    ["nombre" => "Teclado", "precio" => 25.00],
    ["nombre" => "Ratón", "precio" => 12.50],
    ["nombre" => "Monitor", "precio" => 150.00]
];

foreach ($productos as $indice => $producto) recorre cada registro. El índice permite mostrar la numeración y $producto["nombre"] y $producto["precio"] recuperan los campos de cada fila.

¿Y si quisiera hacerlo con cookie o hidden?

Es posible guardar una lista pequeña serializada en una cookie, pero el usuario puede modificarla, hay límites de tamaño y no conviene usarla como almacenamiento fiable. Para aprender, es mejor la sesión. Con hidden, el navegador debe reenviar la lista en cada formulario y el usuario puede alterar los datos; por tanto, no es adecuado para mantener una lista confiable. Si los registros deben sobrevivir al cierre de sesión o compartirse entre dispositivos, utiliza una base de datos.
